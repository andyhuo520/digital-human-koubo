# 封面 + 首帧

每条片子默认都做封面，并接在成片开头当第一帧。抖音、视频号、X、B 站默认都取首帧做封面，这样发布时不用再单独上传封面。

## cover.json
放在工程根目录，所有路径都相对它。

```json
{
 "ratios": ["16:9", "3:4"],
 "theme": "paper",
 "accent_color": "#f4212e",
 "kicker": "X 官方新功能 · UNDER THE HOOD",
 "title": "帖子被限流了？",
 "accent": "一个链接自查",
 "sub": "哪几条被打标签 · 什么原因 · 影响多大",
 "tags": ["官方报告", "每月更新", "逐条列出"],
 "url": "x.com/i/jf/under_the_hood",
 "host": {"video": "film/public/host.mp4", "t": 16.94},
 "props": [
  {"image": "film/public/shots/rep_oct.png", "crop": [90, 630, 1080, 1135]},
  {"image": "film/public/shots/rep_sep.png", "crop": [60, 40, 1100, 520]}
 ]
}
```

| 字段 | 写法 |
|---|---|
| ratios | 和成片画幅一致的那个必出（16:9 / 9:16），3:4 给小红书 |
| theme | paper（浅底点阵，默认）/ dark（X 黑） |
| kicker | 小字栏目名 / 来源，例如「X 官方新功能 · UNDER THE HOOD」 |
| title | 钩子问题或结论，≤8 字，黑色大字 |
| accent | 强调句，≤6 字，红色更大字（9:16 版是黄色） |
| sub | 一句话说清看完能得到什么 |
| tags | ≤3 个，黑底白字 |
| url | 链接或号召，等宽字体 |
| host | `video + t`：从主播视频取一帧，先用 `--candidates` 挑；也可以写 `image` 用定妆照 |
| props | ≤2 张斜放的证据卡（官方截图、产品界面、作品帧），`crop` 用原图像素坐标，只截最有说服力的那块 |
| disclosure | 角标，默认「内容由 AI 数字人演绎」（红线要求，别删） |

文字都会自动缩小到不超出栏宽，不用手算字号。

## 三种版式
- **16:9**：左边文字栏宽 880px（栏目名 → 标题 → 强调句 → 副标题 → 标签 → 链接），右边主播卡，两张证据卡斜着压在主播卡后面。
- **9:16**：主播铺满画面，下方加暗色渐变，字压在渐变上（白色标题、黄色强调），证据卡浮在主播胸口右侧。
- **3:4**：标题在上面，主播卡在右下，证据卡在左中，标签和链接在左下。

## 接到首帧
`python3 scripts/cover_first.py 成片.mp4 cover/cover_16x9.jpg 交付.mp4 [--hold 0.5]`
- 封面停 0.5 秒后硬切进正片，声音整体后推 0.5 秒，前面补静音。成片已经是 -16 LUFS 的话，接完响度不变。
- 抽 0 秒、0.45 秒、0.55 秒三帧确认：前两帧是封面，第三帧是正片。
- 交付的主文件 = 带封面的版本；不带封面的版本另存为 `_无封面.mp4`。

## 挑帧
- 嘴闭着或微笑；别挑正在念字、嘴型张大的帧，也别挑闭眼的。
- 手势自然（叉腰、摊手），不挡脸。
- 和片中主播卡是同一个人、同一身衣服；Grok 段间会有轻微差异，选和参考图最像的那段。
