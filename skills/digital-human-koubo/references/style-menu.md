# 剪辑风格菜单（先选风格，再写稿）

用户把内容发过来以后，**先诊断内容，推荐 2 个风格，让用户选**；用户点了风格再写稿、切段、报价。同一份内容换风格，稿子的写法、段落长短、全屏/小窗的比例、成本都不一样，所以风格要最先定。

## 第一步：内容诊断（30 秒内给结论，不用问用户）
读完用户的内容，写一行诊断：

> 「这是一条 **产品推荐**（第一人称体验、要号召下单），素材里有 **3 个作品可展示**，适合 **竖屏 60–90 秒**。」

看这几样：
| 信号 | 指向 |
|---|---|
| 有事件 / 数据 / 时间线 / 「为什么」「怎么回事」 | A 小林式解说 |
| 第一人称安利、带货、种草、吐槽、号召 | B 网红花字口播 |
| 新品 / 新模型 / 新功能发布，有官网、参数、对比 | C 发布解读 |
| 「怎么做」「几步」、有操作界面、命令 | D 保姆级教程 |
| 要多语言、多场景、多个角色或用户本人出镜 | E 多主播接力 |
| 平台是抖音 / 小红书 / 视频号 | 竖屏优先（B），其他风格也可以出 9:16 版 |
| 平台是 B 站 / YouTube / 公众号视频 | 横屏优先（A / C / D / E） |

## 第二步：给用户选
在 Claude Code 里用 AskUserQuestion（一次最多 4 个问题），**第一个选项写推荐理由并标「推荐」**；其他工具（Codex 等）就列编号让用户回复数字。同时把对应预览图发给用户看（`assets/styles/*.jpg`，SendUserFile）。

一次问完，别来回问：
1. **风格**：推荐的 2 个 + 「其他风格」（列出剩下的名字）
2. **比例和时长**：例如「9:16 · 约 60 秒（推荐）」/「16:9 · 约 3 分钟」/「两个都要」
3. **花字强度**（只对 B，其他风格可略）：克制 / 标准（推荐）/ 热闹
4. **主播**：白背心数字人 / 用户本人的数字人 / 两位接力 / 动物角色

用户回「都行」「你定」时就按推荐走，并在回复里写一句「按推荐：B · 9:16 · 标准」。

选完把结果写进工程目录 `brief.json`：
```json
{ "style": "B", "ratio": "9:16", "length_s": 60, "huazi": "标准", "host": ["tank"], "languages": ["zh"],
  "platform": "抖音", "cta": "去试试 Renoise", "showcase": ["show/a.mp4"], "notes": "用户说别太吵" }
```
后面的写稿、切段、剪辑全按 brief.json 来；用户中途改主意就改这个文件。

## 五种风格

### A · 小林式解说（财经 / 科技事件）
![](../assets/styles/A_xiaolin_explainer.jpg)
- **适合**：一件事讲清楚——暴雷、收购、行业格局、「为什么 XX」。3–20 分钟。
- **画面**：主播全屏 ↔ 缩成小窗、旁边上图表 / 文件标黄 / 时间线 / 竞猜；章节标题卡；拟人贴纸独白。每分钟 9–12 次画面切换，主播全屏一次不超过 12 秒，累计不超过全片 20%。
- **13 种场景**（templates/lin-169）：景深字、紫色题板+主播小窗、B-roll+数据卡/标签/大数字/横幅、利率大卡、先 ?% 后揭晓、推导逐行、结论砸下、公式逐项长出、算例填数、条形图/瀑布/曲线、3D 贴纸四宫格。详见 references/lin-style.md。
- **稿子**：三种骨架（危机型 / 博弈型 / 悖论型），每分钟 1–2 个设问、3–4 个带参照物的数字；至少 3 个活人感手法（替观众质疑、生活比喻、坦白没查到、先说答案…）。
- **怎么做**：`bash scripts/new_edit.sh lin-169 <工程>`，写 plan.json（时间写「@段号:触发词」）→ `lin_scenes.py` → 渲染。B-roll 用 Wan 3.0 生成（720p 5 秒 60 积分/段，一期 10–12 段）。音效用 `lin_sfx.py`（earshot），混音用 `lin_mix.py`。流程见 references/lin-style.md。纯图表、不出镜的长片仍可走 `finance-explainer` 的引擎。
- **红线**：只学结构和手法，不用小Lin本人的脸、声音、布景、口头禅原句；每个数字进 facts.md 带出处。
- **默认包装**：开场砸字/搜索框 → 证据截图 → 主问题 → 第一章；全片进度条 + 出处角标 + 每章复盘板；数字用 Counter、原文用 DocFocus、地点用 MapRoute、揭晓前 PollPop。
- **成本**：口播全部按 720p 拍（小窗里有方形大窗时 480p 会糊），5–6 分钟约 6,000 积分；B-roll 约 720 积分、贴纸 23 积分。剪辑、修念错、音效都是本地做，0 积分。

### B · 网红花字口播（竖屏）
![](../assets/styles/B_huazi_koubo.jpg)
- **适合**：产品安利、带货、种草、观点吐槽、起号。30–120 秒。
- **画面**：主播竖屏全身 / 半身；逐字弹跳字幕 + 关键词变色放大；脸两侧弹动态表情；跳切交替推近 + 重点词推一下；盖章、砸屏大字、对比条、清单卡；展示作品时主播缩右下小窗；结尾号召大字。
- **稿子**：开头 3 秒钩子（反问 / 反常识 / 数字），一段一个点，口语、短句，结尾明确号召。
- **怎么做**：`templates/huazi-916`（数据驱动，改 edit.json 就行），详见 references/huazi.md。
- **花字强度**：克制（知识类、品牌号）/ 标准（大多数）/ 热闹（搞笑、带货、年轻向）。
- **默认包装**：0–2 秒数字钉子或倾斜金句 → 弹幕替观众质疑 → 关键词三连；每 3 秒一个刺激点，截图用竖屏 ZoomFocus，中段 0.5 秒故障插屏号召。
- **成本**：全屏 720p 为主（17 积分/秒）。

### C · 发布解读（横屏侧边讲解）
![](../assets/styles/C_launch_side.jpg)
- **适合**：新模型 / 新产品 / 新版本发布，30–90 秒的快讯解读。
- **画面**：开头 3 秒快闪砸字；主播竖屏放左侧，右侧放代码动效 / 参数气泡 / 对比卡 / 官网截图；结尾金句 + 链接。
- **怎么做**：参考实现 `templates/reference/launch-169/src/Film.tsx`（人物卡居中 ↔ 侧边弹簧缩放 + 5 场 B-roll）。内容场景每期重写。
- **默认包装**：产品冷镜头 + 主题句 → 关键词三连 → 里程表 / 玻璃面板 / 官方文档一个证据 → 反转 → 4–8 秒片头；主播多档景别跳切，参数用 SpecCard。
- **成本**：中等，主播全程出镜但多为 480p 侧边。

### D · 保姆级教程（横屏）
![](../assets/styles/D_tutorial.jpg)
- **适合**：「几步做出 XX」、工具上手、安装配置。3–8 分钟。
- **画面**：顶部步骤进度条；左侧界面仿真（浏览器 / 终端 / 聊天窗逐字打出、橙色圈出按钮）；主播在右侧小窗，讲概念时全屏；插入真实演示对比片段。
- **稿子**：每步「做什么 → 怎么点 → 怎么确认成功」，命令写成好念的样子，真实数字（价格、积分）进画面。
- **怎么做**：参考实现 `templates/reference/tutorial-169/src/Tutorial.tsx`（tl.json 驱动，每段一个 Scene）。
- **默认包装**：搜索框打字开场 → 成品快闪 → 步骤徽章常驻；每个「点哪里」用 ZoomFocus + 手绘圈，坑用 FreezeFrame「等等！」，每大步后复盘板。
- **成本**：pip 段 480p，最省。

### E · 多主播接力 · 多语言 · 多场景
![](../assets/styles/E_multi_host.jpg)
- **适合**：展示数字人能力本身、品牌出海、一个产品多场景（直播带货 / 广告 / 导览 / 讲师）、动物角色、用户本人出镜。
- **画面**：冷开场多语言快闪（一句整句 + 五语各 1 秒问候）；两位主播横竖混排接力；全屏场景片段带语言标签和中文翻译；结尾快闪 + 同框。
- **怎么做**：参考实现 `templates/reference/multihost-169/src/Tutorial.tsx`（nar / clip / title / outro 四类条目）。场景图先用 GPT Image 2.5 合成（人物参考图 + 场景描述，2k 23 积分），再交给 Grok 开口。
- **坑**：Grok 横屏口播偶尔自己烧字幕，生成完抽帧检查；外语台词提前翻好，生成后按语言回听；冷门汉字读音（如日语「提灯」）可能念错。
- **默认包装**：多语言快闪 / 预告闪回 → 逐词堆叠 → 标题卡；换主播打字名牌，去过哪儿用地图航线，换场景用对比擦除或纸张拼贴。
- **成本**：最高——场景图 + 全屏 720p 多。

## 包装
每种风格都自带一套默认包装（上面每节的「默认包装」，完整配置在 references/packaging-presets.json）。问用户时可以加一题「包装节奏」：克制（MKBHD 式，字少留白）/ 标准（推荐）/ 快节奏（MrBeast 式，每 3 秒一个刺激点）。

## 组合
- 同一条内容可以「A 横屏长版 + B 竖屏切片」一起出：先做 A，再从里面挑 3–4 段最有冲击的口播套 B 模板（口播片段不用重拍）。
- 用户只想先看效果：先拍第 1 段 + 用 B 模板出 15 秒样片，确认后再批量。
